# Xmas storage

A simple web app for tracking Christmas stock: snacks, treats, alcohol & drinks and the big Xmas dinner.

- Add items with a category and expiry date
- Items expired or expiring within 30 days are flagged on the Home tab
- Tabs for each category, plus Settings with backup download and restore
- Barcode scanning fills in product names (Open Food Facts); needs camera access and internet
- Data is saved in your browser (localStorage), so it stays on the device you use

## Run it

Open `index.html` in a browser. No build step.

## Host on GitHub Pages

Put the files in a repo root, then Settings > Pages > Deploy from a branch > `main` / root.
